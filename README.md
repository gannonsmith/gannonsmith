## Selected work

### [Jester](https://github.com/gannonsmith/jester)
A C++ chess engine built from the rules up, including move generation, evaluation, and search.

### [Bubble](https://gannonsmith.dev/#projects)
A secure location-sharing and messaging project built with Rust and Axum. The portfolio write-up covers the design decisions and tradeoffs.

### [Smith–Waterman accelerator](https://gannonsmith.dev/#projects)
A hardware implementation of sequence alignment focused on making a computationally expensive algorithm practical through parallelism.

### [NPAIC](https://github.com/gannonsmith/npaic)
Knowledge-grounded NPC dialogue generation with personality and memory—an exploration of how context can make generated interactions feel more coherent.

### [Yodel](https://github.com/gannonsmith/yodel)
A satirical Cincinnati news outlet where generative AI drafts the jokes and a human editor decides what gets published.
